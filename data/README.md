# Datasets (synthetic)

All data here is **synthetic**, generated by the simulator (`make data`, seed 42). It is not real company data.
Period: 2023-01-02 to 2025-12-28, daily, 27 Brazilian UFs. Calibrated to ~80,000 new subscribers/month and a
R$ 3.25M/month media budget.

| File | Rows | Grain | Real-world analogue |
|---|---|---|---|
| `campaign_daily.csv.gz` | 294,840 | day x UF x channel | Ad platform / BI export |
| `creative_daily.csv.gz` | 21,706 | day x channel x creative (national) | Creative report |
| `creative_catalog.csv.gz` | 394 | one row per creative | Creative library / asset tracker |
| `outcomes_daily.csv.gz` | 29,484 | day x UF | Subscription billing / CRM |
| `ground_truth.csv.gz` | 29,484 | day x UF | **Does not exist in real life** (benchmark only) |
| `creative_truth_daily.csv.gz` | 21,706 | day x creative | **Does not exist in real life**: true incremental subs caused by each creative |
| `creative_truth.csv.gz` | 394 | one row per creative | **Does not exist in real life** (benchmark only) |

## campaign_daily
`date`, `geo` (UF), `platform` (google / meta / other), `channel`, `spend_brl`, `impressions`, `clicks`,
`video_views`, `platform_reported_subs` (subs a last-click proxy credits to the channel; stand-in for a dashboard's
reported conversions).
- `clicks` is empty for TV. `video_views` is filled only for video channels (YouTube, Meta Reels video, Meta Advantage+, PMax).
- Channels: tv, affiliates, youtube, search_brand, search_generic, app_campaigns, pmax, meta_advantage, meta_reels_video, meta_remarketing.
- Derive CPM = spend / impressions x 1000, CTR = clicks / impressions, CPC = spend / clicks, view rate = views / impressions.

## creative_daily / creative_catalog
- `creative_daily`: `date`, `channel`, `platform`, `creative_id`, `age_days` (days since launch), `spend_brl`, `impressions`,
  `clicks`, `video_views`, `platform_reported_subs`. Per channel and day, creative rows add up to the national totals of
  `campaign_daily`.
- `creative_catalog`: `creative_id`, `channel`, `platform`, `format` (reels_video, static_image, carousel, video_15s, spot_30s,
  responsive_search_ad, ...), `theme` (futebol_ao_vivo, filmes_telecine, bundle_streamings, oferta_preco, lancamento),
  `plan_promoted`, `hook`, `duration_sec`, `launch_date`, `end_date`. Some creatives launch before 2023-01-02.
- Creatives differ in CTR and CPM (quality), lose CTR as they age (fatigue) and **have a causal effect**: each has a hidden lift
  (theme, format, noise) that scales the incremental subs of its channel, weighted by the spend it receives. Price-offer
  creatives (`oferta_preco`) get more clicks but less causal lift, so clicks are only a weak proxy (correlation ~0.3).

## outcomes_daily
`date`, `geo`, `population`, `event_intensity` (demand-event calendar: sports season starts, launches, Black Friday),
`new_subs`, `new_subs_premiere_futebol`, `new_subs_telecine`, `new_subs_claro_tv_bundle`, `new_mrr` (R$).

## ground_truth / creative_truth
`true_organic`, `true_incr_<channel>`, `true_incr_<channel>__<plan>` (expected subs caused by each channel, by plan);
`quality`, `causal_lift` and `fatigue_days` per creative; `creative_truth_daily` has the true incremental subs per creative and day. Use only to score a method, never as a model input.

## Not included
Reach / frequency, audience segments, device, placement, and conversion events other than the last-click proxy.
Creative-level data is national (not by UF).
